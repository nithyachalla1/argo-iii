# Contributing to A.R.G.O.

## Branches

Do not develop directly on `main`.

Use descriptive branch names:

```text
feature/urdf
feature/camera
feature/wheel-odometry
docs/setup-guide
fix/cmd-vel-timeout
```

## Commits

Use descriptive commit messages.

Good:

```text
Add initial rover architecture
Document camera interface
Implement wheel odometry
```

Avoid:

```text
stuff
update
changes
fixed
```

## Pull Requests

Before merging:

* Make sure your changes are understandable.
* Test what you changed.
* Update documentation if interfaces changed.
* Get at least one teammate review.
